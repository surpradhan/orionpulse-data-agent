# Prompt Templates

## KPI Summary

Goal: summarize performance
Scope: {region}, {period}
Output: KPI table + short interpretation + risks

## Root Cause

Goal: diagnose decline in {metric}
Scope: {region/category/time}
Output: drivers, evidence, recommended actions

## Forecast

Goal: predict next {n} months for {metric}
Scope: {segment}
Output: forecast points, assumptions, uncertainty notes
