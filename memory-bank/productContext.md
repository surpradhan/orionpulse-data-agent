# Product Context

- Primary users: analysts and business stakeholders who need fast sales insights.
- Main user journeys:
  - Ask natural-language analytics questions.
  - Generate chart-backed insights.
  - Export BI-ready datasets and semantic mappings.
  - Use voice interaction in UI for input/output convenience.
- Business expectations:
  - Accurate KPI calculations and interpretable forecasts.
  - Safe SQL/query execution surfaces.
  - Controlled access to sensitive/heavy operations (exports/admin flows).
