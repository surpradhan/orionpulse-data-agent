## Known issues / caveats
- Statsmodels may emit convergence warnings on some series.
- Browser speech APIs vary by browser/platform support.
- If auth is not required and tokens are unset, API allows dev-mode access.
- Test runs can show Matplotlib/Tkinter teardown warnings on Windows if GUI backend is touched; prefer non-interactive backend settings during automated tests.
- Current Ruff policy (`line-length=100`) surfaces many pre-existing long-line/import-order violations outside the scope of this cycle.
