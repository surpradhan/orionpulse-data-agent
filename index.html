Capabilities

Everything you need for
sales data intelligence

From raw SQL to boardroom-ready narratives — deterministic by default, LLM-augmented when it matters.

📈

KPI Analytics

Monthly and quarterly summaries covering net revenue, gross margin, units sold, and ASP. Regional leaderboards with channel context and product ranking by margin.

🔮

Multi-Horizon Forecasting

Auto-selects the best model (ARIMA, ETS, moving average) per metric. Supports up to 24 periods with confidence intervals, MAPE/SMAPE diagnostics, and residual analysis.

🚨

Anomaly Detection

Statistical baselines with configurable sigma thresholds. Detects point anomalies and contextual shifts across any numeric metric with full trace artifacts.

📊

Chart Generation

Thread-safe Matplotlib/Seaborn charts output as PNG or SVG. Covers KPI trends, regional bar charts, product margin plots, and forecast visualizations with CI bands.

🧩

BI Spec Generation

Generates structured JSON specs for dashboard tools and narrative storyboards. Export analytics packages in CSV or Parquet with semantic KPI metadata.

🔒

Security-First Design

Three auth profiles (DEV_OPEN → PROD_STRICT), read-only SQL enforcement with allowlist validation, token-based RBAC, rate limiting, and XSS sanitization — no external auth deps.

Execution Modes

The right engine
for every query

Choose speed, intelligence, or let OrionPulse decide automatically.

Deterministic

Fast & Auditable

SQL-only execution. No LLM calls. Returns in milliseconds with full trace IDs and reproducible results. The default for CLI usage.

No API key needed <50ms latency 100% reproducible
LLM-Orchestrated

Rich Reasoning

Claude or any OpenAI-compatible model drives multi-step tool calls. Generates narrative summaries, business recommendations, and follow-up insights.

Narrative output Multi-step planning MCP tool calls
Auto

Adaptive Hybrid

Deterministic path runs first. If confidence is below threshold, falls back to LLM orchestration automatically. Default for the Web API.

Best of both worlds Confidence-gated Web default

Model Context Protocol

11 tools, ready for
any LLM to call

Every analytical capability is exposed as a typed MCP tool — composable, safe, and schema-documented.

list_tables() Discover all available tables and analytical views in the database.
describe_table() Return full schema metadata for any table or view.
run_sql() Execute validated, read-only SQL with row limits and injection protection.
kpi_summary() Monthly or quarterly KPI summaries: revenue, margin, units, ASP.
forecast_metric() Time-series forecast with auto model selection and confidence intervals.
anomaly_detection() Statistical anomaly detection with configurable sigma thresholds.
dashboard_spec() Generate a structured JSON dashboard specification for BI tools.
storyboard_spec() Produce a narrative-driven analytics storyboard in structured JSON.
create_sql_view() Admin-only: persist a named analytical view to the database.
generate_chart() Render KPI, regional, margin, or forecast charts as PNG or SVG.
export_analytics() Package query results as CSV or Parquet with KPI metadata.

Quickstart

Up and running
in under 2 minutes

Install & seed database bash 
# Clone the repo
git clone https://github.com/surpradhan/orionpulse-data-agent
cd orionpulse-data-agent

# Create virtual environment
python -m venv .venv && source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Seed SQLite database
python data/init_db.py

# Run preflight checks
python scripts/preflight.py
Start the web server bash 
# Configure environment
cp .env.example .env
# edit .env → set AUTH_PROFILE, optional OPENAI_API_KEY

# Launch FastAPI server
uvicorn src.orion_sales_agent.webapp:app \
  --reload --port 8000

# Chat via CLI
python scripts/ask_agent.py \
  --mode auto \
  --question "What were the top 3 regions by margin last quarter?"

# Or launch MCP server for Claude Desktop
python -m mcp_server.server
