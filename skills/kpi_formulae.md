# KPI Formulae

- **Net Revenue** = `SUM(net_revenue)`
- **Gross Revenue** = `SUM(gross_revenue)`
- **Discount Rate** = `SUM(discount_amount) / SUM(gross_revenue)`
- **Margin** = `SUM(margin)`
- **Margin %** = `SUM(margin) / SUM(net_revenue)`
- **ASP** = `SUM(net_revenue) / SUM(units_sold)`
- **YoY Growth %** = `(current_period - prior_year_period) / prior_year_period`

Always report denominator checks and avoid divide-by-zero.
